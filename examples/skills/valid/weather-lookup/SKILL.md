---
name: weather-lookup
description: Look up the current weather conditions and forecast for any city, including temperature, precipitation, wind, and severe-weather alerts. Use this when a user asks about forecasts, temperature, rain, snow, wind, humidity, or storms for a specific place or time.
---

This skill calls a weather-forecast API for a named location and returns the
current conditions plus a short-range forecast (temperature, precipitation
chance, wind speed, and any active severe-weather alerts).
